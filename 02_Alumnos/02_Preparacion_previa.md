# Antes de venir a clase (flipped classroom)
Tiempo orientativo: 45–60 minutos.
1. Tener instalados Python 3.10+ (recomendado 3.11), VS Code con extensión Python y Git.
2. Repasar `python -m venv .venv`, activación en Windows/macOS/Linux, `pip install -r requirements.txt` y `.gitignore`.
3. Repasar funciones, módulos, excepciones y uso básico de Git (rama, commit y pull request).
4. Leer introducciones de [pytest](https://docs.pytest.org/en/stable/getting-started.html) y [Ruff](https://docs.astral.sh/ruff/).
5. Traer portátil y acceso a GitHub. **No resolver el starter antes de la clase.**

Pregunta de entrada: ¿qué significa que un proyecto funcione en otro equipo sin copiar tu entorno virtual?
